💡 Why Does KNN Outperform Naive Bayes?

1. Violation of Feature Independence: Naive Bayes assumes all features are conditionally independent given the class label. In reality, physical fruit features (e.g. Size & Weight, Sweetness & Ripeness) exhibit non-linear interactions.

2. Local Instance Neighborhoods: KNN is a non-parametric instance-based classifier. It makes no rigid assumptions about underlying probability distributions and adapts naturally to non-linear decision boundaries.

Answer: The objective is to classify apples into two quality categories (Good vs Bad) using supervised machine learning algorithms based on 7 physical and sensory features (Size, Weight, Sweetness, Crunchiness, Juiciness, Ripeness, and Acidity).

Answer: KNN is an instance-based, non-parametric algorithm. When a new apple data point is provided, KNN calculates Euclidean distance to all training samples, finds the k closest neighbors, and assigns the majority class. We chose k=5 (an odd number) to prevent ties in binary classification and achieve optimal bias-variance tradeoff.

Answer: KNN relies strictly on distance calculation ($d = \sqrt{\sum (x_i - y_i)^2}$). If features have unequal ranges or variances, variables with larger magnitudes would overpower the distance formula. StandardScaler standardizes features to zero mean and unit variance ($z = (x - \mu) / \sigma$), improving KNN accuracy to 87.5% - 90%.

Answer: Gaussian Naive Bayes applies Bayes' Theorem with the strong assumption of conditional independence among all features. In agricultural fruit metrics, attributes like sweetness, juiciness, and ripeness correlate naturally. KNN does not make this independence assumption and captures local multi-dimensional relationships.

Answer: We performed an 80/20 train-test split with stratification. In addition to Accuracy, we measured Precision (minimizing false positives), Recall (capturing all good apples), F1-Score (harmonic mean), and ROC-AUC (94.36% for KNN vs 83.05% for Naive Bayes).
